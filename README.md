# E-Commerce Sales Data Analysis 📊

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data to uncover meaningful business insights such as sales trends, category performance, regional distribution, and customer demographics. An interactive dashboard is built to visualize key performance indicators and patterns that help in data-driven decision-making.

The project was developed as part of an **Industry Internship** and demonstrates an **end-to-end data analysis workflow**, from data preprocessing to deployment.

---

## 🎯 Objectives
- Analyze historical e-commerce sales data
- Identify sales trends over time
- Understand category-wise and region-wise performance
- Analyze customer age distribution
- Build an interactive and user-friendly dashboard
- Deploy the application as a web-based solution

---

## 📂 Dataset Description
The dataset used is an **E-Commerce Sales Dataset (CSV format)** containing order-level details such as:
- Order Date
- Sales
- Category
- Sub-Category
- Region
- Customer Age

The dataset is used only for analytical and academic purposes.

## 📊 Analysis Performed
- **Sales Trend Analysis**: Time-based sales patterns

- **Region-wise Sales Distribution**: Regional contribution to sales

  - Total Sales
  - Average Sales
  - Total Orders

## 🚀 Deployment
The project is deployed using **Streamlit Cloud**.

### Deployment Steps:
1. Upload project files to a GitHub repository
2. Include required files:
   - `app.py`
   - `requirements.txt`
   - Dataset CSV file
3. Connect GitHub repository to Streamlit Cloud
4. Select the main application file and deploy
